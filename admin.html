Admin mode

Admin mode saves your changes straight to the site's GitHub repo, so it needs a GitHub access key. You only set this up once per device.

  1. Create a key on GitHub ↗
  2. On that page, set:
    • Repository access: Only select repositories → dnd-characters
    • Permissions → Repository permissions → Contents: Read and write
    • Expiration: your choice (a year is sensible)
    Then click Generate token.
  3. Copy the key (it starts with github_pat_) and paste it here:
Advanced

The key is stored only in this browser. Anyone who has it can edit the site, so don't share it. You can delete it any time in GitHub → Settings → Developer settings → Personal access tokens.
